# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2024-01-01

### Added
- Initial release
- Protocol adapters for Aave, Compound, Uniswap, Curve, Yearn (mock data)
- APY calculator with compound interest formulas
- Risk scoring engine (TVL, age, audit, chain diversity)
- Portfolio optimizer with greedy allocation strategy
- CLI interface with rich output (pools, risk, optimize commands)
- Pydantic data models with validation
- YAML configuration for protocols and risk parameters
- Comprehensive test suite (40+ tests)
- GitHub Actions CI workflow
- Makefile for development commands
